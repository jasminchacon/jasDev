# Jas Dev Portfolio

Portfolio personal responsive construido con HTML5, TailwindCSS por CDN, CSS modular y JavaScript vanilla.

## Estructura

```text
portfolio/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

## Ejecutar

Abre `index.html` directamente en el navegador o sirve la carpeta con cualquier servidor estático:

```bash
python3 -m http.server 8080
```

Luego visita `http://localhost:8080`.

## Incluye

- Navbar sticky con blur, scroll spy y menú mobile animado.
- Hero responsive basado en el mockup.
- Skills, Sobre mí, Proyectos con Swiper, Formación, Contacto y Footer.
- Animaciones con Intersection Observer.
- Validación de formulario con JavaScript vanilla.
- Metadatos SEO, OpenGraph, Twitter Cards y favicon.
